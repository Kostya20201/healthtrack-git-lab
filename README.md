## About this repository

Цей репозиторій створено для виконання лабораторної роботи №8 
та використовується як навчальний приклад керування проєктом HealthTrack
за допомогою Git та GitHub.

У межах роботи тут демонструється створення гілок, комітів, pull request'ів,
а також базова структуризація документації для мобільного додатку HealthTrack.
